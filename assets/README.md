# Harper's avatar

Drop Harper's portrait here as **`harper.png`** (or set a different path via the
`HARPER_AVATAR` env var). JPG works too — name it `harper.jpg` and set
`HARPER_AVATAR=assets/harper.jpg`.

Until you add a file, the app shows a built-in placeholder face.

**Best results:** a square image, head-and-shoulders, looking toward the camera,
plain/clean background. It gets cropped into a circle.

See the main README for the suggested image-generation prompt.
